# API HUB — Frontend

Vue 3 前端项目，为 API HUB 后端提供管理界面。

## 技术栈

- **构建工具**: Vite
- **框架**: Vue 3 + TypeScript
- **路由**: Vue Router
- **状态管理**: Pinia
- **测试**: Vitest
- **代码规范**: ESLint + Prettier + oxlint

## 快速开始

```sh
npm install
npm run dev
```

### 构建

```sh
npm run build
```

### 单元测试

```sh
npm run test:unit
```

### 代码检查

```sh
npm run lint
```
